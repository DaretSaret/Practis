Задача: Разработать пользовательский контрол для реализации индикации. Контрол должен взаимодействовать с коллекцией изображений и в зависимости от параметра Value (int) выводить определенный элемент.

Используемые библиотеки:
using System.Collections.Generic;
using System.Windows;
using System.Windows.Controls;
using System.Windows.Media.Imaging;
using System;
using System.Windows.Threading;

Возникшие трудности: реализация анимации для коллекции изображений, реализация методов для показа и смены изображений
